IA Local — $0 / Privacidad total
1. Instala Ollama: curl -fsSL https://ollama.com/install.sh | sh
2. Descarga el modelo: ollama run qwen2.5-coder
3. Graphtyn se conecta automáticamente a http://localhost:11434
